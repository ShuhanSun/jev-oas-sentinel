# Roadmap

JEV OAS Sentinel is a public alpha. The roadmap prioritizes evidence, safe adoption, and interoperability over adding unbounded AI behavior.

## Now

- Validate the GitHub Action from an independent consumer repository.
- Expand the semantic routing benchmark with community-submitted API promises.
- Improve pull-request annotations and SARIF source locations.
- Document TypeSafe Jev cost and latency from representative repositories.

## Next

- Add reusable policy profiles for common compatibility standards.
- Cache semantic decisions by normalized operation change and pinned model.
- Produce machine-readable benchmark snapshots across Sentinel versions.
- Add optional integrations with established structural OpenAPI diff tools.

## Later

- Evaluate OpenAPI 3.1 edge cases and larger multi-file specifications.
- Explore organization-wide policy distribution and centrally managed suppressions.
- Publish a labeled, community-reviewed semantic compatibility dataset.

Roadmap items are directional, not commitments. Open a feature request with a concrete API change and consumer impact to help prioritize them.
